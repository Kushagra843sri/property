## [Unreleased]

### Added

- Deployment guide, admin guide and handover notes (drafts); `create-admin` command; pluggable rate-limit storage.

- Admin panel: sign in, dashboard, listings manager with photo upload and reordering, leads with status and notes, interests, enquiries, CSV export.

- Public website: home (Buy and Rent entries, PG and room quick links, optional 3D hero), listings with URL-synced filters, property detail with gallery, contact, about, privacy and terms (drafts), sitemap and robots.
- Accounts: OTP signup/login dialog with consent, "Interested" with resume after sign-in, My account (interests, name, consent withdrawal, account deletion).
- Property types: flat, shop, office, PG room, furnished room (BHK for flats only).
- Green and gold brand theme for Shree Shyam Properties.

- Core backend: OTP signup/login with consent, sessions, public listings API with filters, "Interested" with dealer notification, contact enquiries, admin API (listings, images, leads, CSV export, stats), seed script.

- Project scaffold: Next.js client, Express API, env validation, security middleware, CI.
